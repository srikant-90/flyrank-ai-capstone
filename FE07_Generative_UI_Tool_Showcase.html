1. Server-Side Tool Contract Documentation

The AI route defines two server-side tools backed by Zod schemas with model guidance descriptions:

Tool 1: auditTaskRisk

const auditTaskRiskSchema = z.object({ taskTitle: z.string().describe("The title or description of the task being audited"), category: z.enum(["Frontend", "Backend", "DevOps", "Design", "Database", "General"]), complexity: z.enum(["low", "medium", "high", "critical"]), estimatedHours: z.number().describe("Estimated hours needed to complete the task"), daysUntilDeadline: z.number().describe("Days remaining until the target deadline"), simulateError: z.boolean().optional().describe("Simulate an audit failure for testing State 4 rendering"), });

2. The 4 Tool Lifecycle Part States

State 1: Input Streaming / Tool Call Pending State 1

Question Answered: "What is the AI doing right now?"

Visual Treatment: Glassmorphic animated loading card with glowing pulse border, radar spinner, and text Executing Tool [auditTaskRisk]....

State 2: Input Available / Inspection Drawer State 2

Question Answered: "With what typed inputs & parameters was the tool called?"

Visual Treatment: Clean parameter pill tags displaying key-value data (Category, Complexity, Hours, Deadline) with an expandable JSON viewer.

State 3: Output Available (Generative UI Component) State 3

Question Answered: "What structured output came back from the tool?"

Visual Treatment: Interactive Task Risk Audit Score Card featuring an animated SVG Radial Health Gauge, color-coded Risk Level Pill (Green/Yellow/Orange/Red), 3-stat metric grid, Risk Factor Blockers list, and Recommended Action Plan.

State 4: Output Error / Failed Execution State State 4

Question Answered: "What went wrong during execution?"

Visual Treatment: Designed dark-red error card with Alert Shield icon, failure cause diagnostic text, and an interactive "Retry Audit" button (no raw crashes or unformatted JSON dumps!).

3. Verification & How to Test

  1. Open https://flyrank-ai-capstone.vercel.app/chat.
  2. Click "⚡ Audit High-Risk Task" to see States 1, 2, and 3 (Generative UI Score Card & SVG Health Gauge).
  3. Click "⚠️ Test Error State" to see State 4 (Designed Error Card with Retry Button).
