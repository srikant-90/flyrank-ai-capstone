The Portfolio Rule & Visual Restraint

If a design is the most memorable thing on the page, something is backwards. People visit to see verified technical work (working agent tools, evaluation logs, clean code). A quiet, confident frame makes the work look valuable, not smaller.

Typographic Hierarchy

HEADINGS & UI
Geist (SemiBold 600, Bold 700)

Engineered specifically for developer interfaces. Tight letter tracking (`-0.5px`), strong visual structure, and high legibility at large display sizes.

BODY & CODE
Inter (Regular 400, Medium 500)

Clean neutral grotesque with balanced x-height for long-form case studies. Paired with JetBrains Mono for unambiguous code schemas and API endpoints.

Two-Line Reusable Style Guide (For AI Workspace Prompts)

COPYABLE STYLE SNIPPET Typography: Geist / Inter (weights 400, 600, 700) + JetBrains Mono for code.
Palette: #090D16 (canvas), #131B2E (card), #F1F5F9 (text), #94A3B8 (muted), #14B8A6 (accent), #1E293B (border). Spacing: 8px grid, calm frame where technical proof is the loudest element.

Part 4: Kill Your Darlings — Image Curation & AI Rejection Log

AI can generate a hundred images in minutes. The real skill is deciding which one serves proof, rejecting generic “AI slop,” and knowing when real captures of code and terminal sessions beat anything generated.

1. Rejected Concept: Floating Purple 3D Neural Network with Neon Rings
REJECTED (AI SLOP)
Prompt: "Futuristic neural network glowing purple and cyan, 3d render, octane render, 8k, digital intelligence."

The Judgment: Violates the anti-cliché rule (“No Purple on Dark”). Recruiter instantly recognizes it as generic Midjourney stock filler with zero connection to the arXiv REST API or Python tool-calling code. It obscures the headline and signals superficiality.

✓ Replacement: Clean white headline over whitespace with a crisp, high-contrast status pill badge.
2. Rejected Concept: Cybernetic Cyborg Head Dissolving into Matrix Code
REJECTED (MISLEADING SCI-FI)
Prompt: "Humanoid AI robot thinking with data streams in background, cinematic lighting, hyperrealistic."

The Judgment: Perpetuates false sci-fi clichés. The capstone is about practical software engineering: Python agents, API schema validation, and structured prompt engineering—not sentient cyborgs. Signals an amateur hobbyist rather than an engineer.

✓ Replacement: A real terminal session capture showing `httpx.get("https://export.arxiv.org/api/query")` returning 200 OK.
3. Rejected Concept: Glassmorphic Iridescent Spheres with Liquid Gradients
REJECTED (DECORATIVE NOISE)
Prompt: "Abstract glassmorphism 3d pastel shapes, frosted glass sphere floating, apple style wallpaper."

The Judgment: Visually noisy and distorts text contrast. It distracts the visitor's eye away from the case studies and onto meaningless decorative blobs.

✓ Replacement: Solid `#090D16` canvas with subtle `#1E293B` structural 1px grid borders.
4. Rejected Concept: Synthetic AI-Generated Corporate Suit Portrait
REJECTED (INAUTHENTIC)
Prompt: "Corporate portrait of young professional software engineer in modern office, photorealistic, 85mm."

The Judgment: Synthetic airbrushed skin creates an immediate “uncanny valley” reaction that destroys visitor trust. In an AI engineering portfolio, authenticity and verifiable proof are paramount.

✓ Replacement: An authentic developer photograph paired with verified links to GitHub repositories.

Summary: Amateur vs. Intentional Design Choices

Reads as Amateur (Rejected) Reads as Intentional (Implemented)
Three or four clashing fonts, decorative typefaces. Two disciplined fonts: Geist (headings) + Inter (body) + Mono for code.
Five bright colors and glowing purple gradient borders. Tight palette: near-black, slate surface, near-white, single mint accent.
A generated “AI slop” hero image (neon cyber-head or floating orb). A clean, authoritative claim over whitespace with real terminal code captures below.
Crammed elements with inconsistent margins and padding. Generous 8px modular spacing and 64px section breathing room.
Design competes with the content for attention. The design is a calm, quiet frame; the technical proof is the loudest element.
