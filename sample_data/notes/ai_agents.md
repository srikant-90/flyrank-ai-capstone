# Notes: AI Agents & Tool Calling

## Overview
AI Agents combine large language models (LLMs) with external tools, memory, and planning frameworks to execute autonomous tasks.

## Key Architectures
- **ReAct (Reason + Act)**: Interleaves reasoning traces with action execution.
- **Function Calling**: Structured API calls emitted by LLM during conversation.

## Grounded Knowledge & Trade-offs
- RAG and fine-tuning are complementary strategies for knowledge retrieval.
- Agents require explicit human-in-the-loop (HITL) approval gates before executing high-risk operations like file deletions or database mutations.
