1. What is a CNAME Record? (Explained for Everyone)

The Phonebook Alias Analogy

Imagine you have a friend named Srikant who frequently moves between apartments. Instead of giving everyone his physical home address (an IP address like 185.199.108.153), Srikant says: "If you want to reach me, look up my alias srikant.flyrank.ai — it points directly to my permanent hosting address srikant-90.github.io."

In the Domain Name System (DNS), a CNAME Record (Canonical Name Record) is an alias entry. It tells the internet: "Don't map this domain directly to a fixed IP address. Point srikant.flyrank.ai to srikant-90.github.io, and let GitHub/Netlify handle the exact IP routing!"

Why We Use CNAME Records for Subdomains

  • Dynamic IP Protection: Cloud hosting providers change server IPs dynamically for load balancing and DDoS shielding.
  • Zero Maintenance: CNAME pointers eliminate manual IP maintenance when hosting infrastructures upgrade.

Target Record Mapping

2. Step-by-Step DNS Resolution Lifecycle

When someone opens a browser and types https://srikant.flyrank.ai, a 7-step journey completes in milliseconds:

STEP 1 Browser & Local Cache Check: The browser checks its local cache for recent IP mappings.
STEP 2 Recursive DNS Resolver: If not cached, the browser queries a recursive resolver (e.g. ISP or Google 8.8.8.8).
STEP 3 Root Name Server (.): The resolver queries the global Root Name Server for .ai authority information.
STEP 4 TLD Name Server (.ai): The .ai TLD server directs the resolver to FlyRank's Authoritative Name Server.
STEP 5 FlyRank Authoritative DNS: FlyRank DNS returns the CNAME record: srikant-90.github.io.
STEP 6 Host IP Resolution: The resolver fetches the active host IP address (e.g. 185.199.108.153) and returns it to the browser.
STEP 7 HTTPS & TLS Handshake: The browser connects over encrypted TLS/HTTPS, verifies the SSL certificate, and displays the padlock 🔒 icon.

3. FlyRank Subdomain Provisioning Checklist

  1. Ops Provisioning: Confirm Ops creates the DNS CNAME record mapping srikant.flyrank.ai -> srikant-90.github.io.
  2. Add Custom Domain in Hosting Settings: In GitHub Pages / Netlify settings, add srikant.flyrank.ai under Custom Domain.
  3. Wait for DNS Propagation: Allow 5 to 15 minutes for global DNS propagation.
  4. Verify HTTPS Certificate: Test https://srikant.flyrank.ai in an incognito window to verify padlock authorization.
