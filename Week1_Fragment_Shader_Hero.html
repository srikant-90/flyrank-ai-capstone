Shader Code Breakdown & Mental Model

Line-by-line breakdown of how the uv, time, and mouse uniforms synthesize into organic fluid motion.

1. UV Normalization & Aspect Correction

Pixel coordinates (gl_FragCoord.xy) vary with resolution. We shift the origin to the center of the screen and divide by the minimum viewport dimension to map st coordinates into a square [-1.0, 1.0] aspect-corrected domain.

vec2 st = (gl_FragCoord.xy - 0.5 * u_resolution.xy) / min(u_resolution.x, u_resolution.y);
2. Mouse Force Field & Vector Falloff

We measure the Euclidean distance between the UV fragment position and u_mouse. An exponential decay function exp(-dist * 3.5) creates a soft, natural liquid force field that bends nearby flow coordinates towards the cursor.

float distToMouse = length(st - u_mouse); float mouseForce = exp(-distToMouse * 3.5); vec2 mouseDisplacement = normalize(st - u_mouse) * mouseForce * 0.25;
3. Multi-Octave Trigonometric Domain Warping

Rather than simple noise textures, we layer 3 rotating octaves of sine and cosine wave harmonics. Each octave multiplies coordinate space, rotates by rotate2D(angle), and shifts phase using u_time to produce fluid liquid turbulence.

float wave1 = sin(q.x * 3.0 + q.y * 2.5 + time * 0.7); vec2 r = rotate2D(-time * 0.12) * (q * 1.6 + vec2(wave1 * 0.5)); float wave2 = cos(r.x * 4.0 - r.y * 3.2 + time * 0.9);
4. Procedural Film Grain & Contrast Vignette

To eliminate color quantization (banding) on dark displays, we add pseudo-random hash noise hash21. Finally, a radial vignette darkens screen edges, guaranteeing high-contrast legibility for overlay headline text.

float vignette = length(st); color = mix(color, vec3(0.035, 0.05, 0.085), smoothstep(0.4, 1.4, vignette) * 0.75); float grain = (hash21(gl_FragCoord.xy + u_time * 10.0) - 0.5) * u_grain_intensity; color += vec3(grain);
🛡️ Responsible Engineering & Performance Fallback Statement
  • DevicePixelRatio Cap: Capped at Math.min(window.devicePixelRatio, 2) to prevent rendering over 4 million pixels on 4K/Retina displays.
  • Visibility & Off-Screen Pause: Listens to document.visibilitychange and uses IntersectionObserver to automatically cancel requestAnimationFrame whenever the tab is hidden or scrolled offscreen.
  • Prefers-Reduced-Motion: Automatically detects system preference for reduced motion and falls back to a single, static WebGL render pass at fixed t = 1.5s without continuous GPU redraws.
