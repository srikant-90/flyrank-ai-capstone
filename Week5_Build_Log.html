3. Build Iteration Diary (What Broke & What Was Fixed)

ITERATION 1

arXiv API XML Namespace Parsing Failure

What Broke: The initial HTTP response returned Atom XML. A naive ElementTree.findall('entry') returned 0 results due to XML namespaces.

Fix Applied: Explicitly registered ATOM_NS = {'atom': 'http://www.w3.org/2005/Atom'} and queried root.findall('atom:entry', ATOM_NS).

ITERATION 2

Tool Import Path Resolution

What Broke: Invoking python src/agent/scout_agent.py threw ModuleNotFoundError: No module named 'tools'.

Fix Applied: Dynamically inserted parent directory into Python path: sys.path.insert(0, str(Path(__file__).resolve().parent)).

ITERATION 3

Interactive CLI Blocking Automated Test Harness

What Broke: Automated evaluation harness stalled waiting for user input().

Fix Applied: Introduced --auto-approve CLI flag for evaluation harness while preserving interactive CLI prompts for manual usage.

ITERATION 4

Multilines Breaking Flashcard JSON Schema

What Broke: Raw paper abstracts with newlines broke JSON formatting.

Fix Applied: Sanitized abstract strings with .replace('\n', ' ').strip() prior to JSON output.
